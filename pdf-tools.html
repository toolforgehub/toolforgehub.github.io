PDF utilities for everyday document work

Use these PDF tools to handle common document tasks without installing desktop software. Choose the task you need, select your PDF files and review the downloaded result before sharing it.

Choose a PDF tool

  • PDF Merger — combine two or more PDF files into one document.
  • PDF Page Extractor — extract selected pages from a PDF.
  • PDF Page Counter — check how many pages a PDF contains.

Which PDF task do you need?

Use PDF Merger when separate documents need to become one file. Use PDF Page Extractor when you only need selected pages from a larger document. Use PDF Page Counter when you need to check document length before printing, uploading or submitting it.

Privacy and file handling

These starter tools are designed to process selected files in your browser. Very large or complex PDFs can use substantial memory and may not work on older phones. Keep an original copy of important documents and verify the final PDF after processing.
