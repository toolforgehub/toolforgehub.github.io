About Time Duration Calculator

Calculate the elapsed time between two clock times and view the result in hours and minutes. If the end time is earlier than the start time, the current calculator treats it as the following day.

How to use Time Duration Calculator

Choose a start time and an end time, then select Calculate Duration. Check the hours and minutes shown in the result.

Frequently asked questions

Can I calculate an overnight shift?

Yes. When the end time is earlier than the start time, the calculator treats the end time as occurring on the next day.
