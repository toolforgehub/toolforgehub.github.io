Report a problem or suggest a feature

Use the public ToolForgeHub GitHub issue tracker to report a broken tool, describe an unexpected result or suggest an improvement. Include the tool page URL, the steps that caused the issue and your browser/device type when relevant.

Open ToolForgeHub Support on GitHub

Before you send a report

  • Describe what you expected and what happened instead.
  • Include a short example using non-sensitive test data.
  • Do not include passwords, payment details, private files or sensitive personal information.

Privacy note

GitHub issue posts are public and may be visible to anyone. Do not use the issue tracker to send confidential information. Read our Privacy Policy for details about website tools and third-party services.
