Practical utilities for developers

Use these tools for common text-based development tasks. They are useful for inspecting structured data, converting values and preparing snippets. Always review generated output before putting it into production.

Browse developer tools

  • JSON Formatter & Validator — format readable JSON, validate syntax or minify data.
  • Base64 Encoder & Decoder — encode or decode text using Base64.
  • URL Encoder & Decoder — encode or decode URL components.
  • HTML Encoder & Decoder — convert special characters to and from HTML entities.
  • HTML Minifier — remove selected comments and unnecessary whitespace.
  • CSS Minifier — reduce CSS whitespace and comments.
  • Regex Tester — test a regular expression against sample text.
  • HEX RGB Converter — convert HEX colors to RGB values.
  • Unix Timestamp Converter — convert timestamps to readable dates and back.
  • UUID Generator — create UUID v4 identifiers.
  • CSV Viewer — inspect CSV text in a table.

Formatting, encoding and minifying are different tasks

JSON formatting changes whitespace for readability without changing the parsed data. Base64 is an encoding scheme, not encryption. URL encoding prepares characters for use in URL components. HTML entity encoding helps represent reserved characters in markup. Minifying removes selected whitespace and comments to reduce text size, but you should test the resulting file in your project.

Use test data for sensitive projects

Do not paste production credentials, access tokens, private keys or confidential customer data into online tools. Check the individual page for its processing method and any external service dependency.
