Resize an image to exact pixel dimensions

Choose an image, enter the output width and height in pixels, and select Resize & Download. The preview canvas shows the resized result before the PNG file is downloaded. Keep the aspect-ratio option enabled to avoid stretching faces, logos and other image content.

How to resize an image

  1. Select an image file from your device.
  2. Enter the required width or height in pixels.
  3. Leave Keep aspect ratio checked to calculate the other dimension automatically.
  4. Review the original and resized preview.
  5. Choose Resize & Download to save a PNG copy.

What is aspect ratio?

Aspect ratio is the relationship between an image’s width and height. For example, a 1200 × 800 image has a 3:2 ratio. Keeping the ratio prevents the image from looking wider or taller than the original. Turn the option off only when you intentionally need exact dimensions and accept possible distortion.

When should you resize an image?

Resize images before adding them to a website, email, online form, presentation or social post. Match the pixel dimensions requested by the destination where possible. Resizing changes dimensions; it is not the same as cropping, and it does not guarantee a smaller file size.

File processing and output

The image is drawn to a canvas in your browser and downloaded as a PNG. The selected image is not intentionally uploaded to our website by this tool. Very large images can use substantial memory, especially on older phones.
