Simple utilities for everyday tasks

This collection brings together tools that do not belong only to text, image editing or calculations. Choose a task, enter the required information and check the result before using it.

Available utility tools

  • QR Code Generator — create a scannable QR image from a URL or plain text. The image is rendered by a third-party service, so do not enter confidential information.
  • Unit Converter — convert common length, weight, temperature and speed units.
  • Random Number Generator — generate random numbers within a chosen range.
  • Password Generator — generate a random password using selected character groups.

Choosing the right utility

Use QR Code Generator when you need a scannable link or text image. Use Unit Converter when values use different measurement units. Use Random Number Generator for simple random selections, and Password Generator to create a unique password for an account. Never reuse passwords between accounts.
