# ToolForgeHub — $0 SEO Setup

## GitHub username
Your GitHub username is the part after github.com/ in your profile URL.
Example: https://github.com/octocat -> username = octocat.
Do NOT use your email address or display name.

## Recommended free URL
Create a PUBLIC repository named exactly:
toolforgehub.github.io

Then upload all files from this folder to the repository root.

Your live URL will be:
https://toolforgehub.github.io/

Before publishing, replace toolforgehub everywhere in:
- robots.txt
- sitemap.xml
- HTML canonical URLs
- Open Graph URLs

## Google Search Console
1. Add the exact live URL as a property.
2. Use URL Inspection on the homepage and important tool pages.
3. Request indexing for key pages.
4. Submit /sitemap.xml in the Sitemaps report.

Google says requesting indexing does not guarantee indexing or a search position. For many URLs, a sitemap is the preferred way to tell Google about pages.
