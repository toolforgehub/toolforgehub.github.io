About HEX to RGB Color Converter

Convert a HEX color value into its red, green and blue components, then preview the color. This is useful when moving between CSS color formats or matching a design specification.

How to use HEX to RGB Color Converter

Enter a HEX value such as #3366FF, then select Convert. Check the color preview and copy the resulting RGB values into your design or stylesheet.

Frequently asked questions

Which HEX formats can I enter?

Use a standard three- or six-digit HEX color, with or without the leading #, as accepted by the input validator.
