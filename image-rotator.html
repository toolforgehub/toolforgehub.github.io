Rotate and flip images online

Use this image rotator to turn a photo by 90, 180 or 270 degrees, or flip it horizontally or vertically. Preview the changes and download a PNG copy without uploading the selected image to ToolForgeHub.

How to rotate an image

  1. Select an image from your device.
  2. Choose a rotation angle.
  3. Optionally flip the image horizontally or vertically.
  4. Review the preview and select Download image.

Rotation and flipping

Rotation turns the image around its centre. Horizontal flip mirrors the image from left to right, while vertical flip mirrors it from top to bottom. The output canvas adjusts its width and height for quarter-turn rotations so the image is not clipped.

Privacy

The image is processed in your browser using the canvas API. The tool does not intentionally upload the selected file to our website. Keep an original copy before editing important images.
