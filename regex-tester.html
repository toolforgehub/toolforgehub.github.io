About Regex Tester

Test a JavaScript regular expression against a sample text string. You can enter a pattern, choose flags and inspect the matched text or a syntax error.

How to use Regex Tester

Enter a regular expression, set any required flags such as g or i, paste sample text and select Test Regex. Review the matches or the reported regular-expression error.

Frequently asked questions

Which regular expression syntax is supported?

This tool uses the JavaScript RegExp engine in your browser, so its syntax and flags follow the browser's JavaScript implementation.
