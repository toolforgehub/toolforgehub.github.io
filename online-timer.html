Free countdown timer online

Set a duration in minutes and seconds, then start the countdown. The timer can be paused, resumed and reset. It is useful for focused work sessions, study breaks, cooking, exercise intervals and short reminders.

How to use the timer

  1. Enter the minutes and seconds.
  2. Choose Start to begin the countdown.
  3. Use Pause to stop temporarily or Reset to return to the entered duration.
  4. When the timer reaches zero, the page displays a finished message.

Does the timer work in the background?

The timer uses your browser clock to calculate the remaining time, rather than relying only on counting interval ticks. However, some browsers suspend background tabs or devices when the screen is locked or power-saving mode is active. Keep the page open and audible alerts are not guaranteed by every browser.
