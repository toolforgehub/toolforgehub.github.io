About Image Dimensions Checker

The Image Dimensions Checker reads an image selected from your device and displays its basic properties, such as pixel width, height and file size.

How to use Image Dimensions Checker

Select an image from your device. Wait for the browser to read it, then review the displayed image dimensions and file information.

Frequently asked questions

Are my pictures uploaded?

The page reads the selected image in your browser and does not intentionally upload the image to the ToolForgeHub website.
