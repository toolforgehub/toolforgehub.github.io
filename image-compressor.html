Compress an image to a smaller JPEG

Select an image and adjust the JPEG quality slider from 10% to 100%. Lower quality settings usually create a smaller file, while higher settings preserve more visual detail. Choose Compress & Download to create a JPEG copy and see the original and new file sizes.

How to compress an image

  1. Select an image from your device.
  2. Move the quality slider to choose a setting.
  3. Use a higher quality value when image detail matters; use a lower value when file size matters more.
  4. Select Compress & Download.
  5. Compare the original and new file sizes, then check the downloaded image before using it.

What does JPEG quality mean?

JPEG is a lossy image format. It reduces file size by discarding some image information. A setting of 0.90 generally preserves more detail than 0.40, but the final size also depends on the original image, dimensions and content. There is no single quality setting that is best for every image.

Important format note

This tool exports a JPEG file. JPEG does not support transparency, so transparent areas in an uploaded image will be flattened in the JPEG output. If you need transparency, keep the original PNG or use a format designed to support it.

Privacy and performance

The image is drawn to a canvas and compressed in your browser; the tool does not intentionally upload your selected image to our website. Large photos may take longer or use significant memory on older devices.
