# ToolForgeHub

Free browser-based utilities hosted on GitHub Pages.

- **Website:** https://toolforgehub.github.io/
- **Repository:** https://github.com/toolforgehub/toolforgehub.github.io
- **Tool pages:** 59 individual tools
- **Sitemap:** 70 URLs, including the homepage, category pages and information pages

## Main categories

Text tools, image tools, PDF tools, developer utilities, calculators and everyday converters.

## Technical files

- `index.html` — homepage and searchable tool directory
- `sitemap.xml` — XML sitemap
- `robots.txt` — crawler guidance and sitemap location
- `assets/style.css` — shared responsive styles
- `privacy.html`, `contact.html`, `about.html` — site information pages

## Privacy and third-party services

Many tools process entered text or selected files in the browser. Some features load public libraries from CDNs or request third-party reference data. See the Privacy Policy for the current service list and disclosures.

## Advertising

The repository contains marked ad placement areas only. Add advertising code only after the publisher account and site are approved, and update the Privacy Policy before enabling third-party advertising.

## Maintenance

Keep the sitemap, homepage directory, page titles, descriptions and canonical URLs in sync whenever pages are added or removed.
