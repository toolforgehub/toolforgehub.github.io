About File Size Converter

Convert a file-size value between common digital storage units. This quick calculator is useful when comparing upload limits, download sizes and storage space.

How to use File Size Converter

Enter a numeric value, choose its current unit and select the destination unit. The converter displays the equivalent size using the selected units.

Frequently asked questions

Are KB and KiB the same?

They are different conventions: decimal KB is 1,000 bytes, while binary KiB is 1,024 bytes. Check which convention a service or device uses.
