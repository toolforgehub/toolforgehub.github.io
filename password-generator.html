Generate a random password

Create a random password from 8 to 128 characters. Choose letters, letters and numbers, or letters, numbers and symbols. The default option uses all three character groups. Select Generate password, then use Copy to copy the result.

How to choose password options

  • Length: longer passwords are generally harder to guess. This tool allows 8–128 characters.
  • Letters + numbers + symbols: uses uppercase and lowercase letters, digits and the available symbols.
  • Letters + numbers: leaves symbols out for services with restricted character rules.
  • Letters only: use only when a website has strict input restrictions.

Password safety tips

Use a different password for every account. Store passwords in a reputable password manager, turn on multi-factor authentication where available, and never send your password to another person in chat or email. A generated password does not protect an account if the device or account itself is compromised.

How randomness works

This generator uses your browser’s Web Crypto random-number generator when available. Keep your browser up to date and use the live HTTPS version of this page. The generated password is shown on your screen so you can copy it; do not leave it visible on a shared device.

Frequently asked questions

Can I create a longer password?

Yes. Set the length up to 128 characters.

Does the tool save my password?

The page does not include an account or password-saving feature. Copy the result to a password manager and close the page when finished.

Should I reuse a generated password?

No. Create a unique password for every account.
