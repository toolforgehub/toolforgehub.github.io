Create a QR code online

Use this free QR code generator to turn a website address or a short text string into a scannable QR code. Enter the content, choose an image size and select PNG or SVG, then generate the code and open or save the result.

How to create a QR code

  1. Paste a complete website URL or enter the text you want to share.
  2. Choose 200, 300 or 500 pixels for the output size.
  3. Select PNG for a common image file or SVG for a scalable vector file.
  4. Select Generate QR Code, then open or save the generated image.
  5. Scan the saved image with a phone before printing or sharing it.

What can a QR code contain?

A QR code can store a website URL or plain text. Common uses include a link on a flyer, a menu, an event page, a contact instruction or a product information page. Make sure the destination URL works and is the correct one before distributing the code.

Choose the right image size

Use 200 px for small digital use, 300 px for general sharing, or 500 px when you need a larger image. For print, test the final physical size and scan distance before producing many copies. Do not stretch a small code into a large blurry image.

QR code generator FAQs

Can I create a QR code for a website link?

Yes. Paste the complete URL, including https://, or enter plain text, choose an output size and format, then generate the QR image.

Should I download PNG or SVG?

PNG is convenient for everyday sharing. SVG is a vector format that can scale cleanly for many design and print workflows.

Does a static QR code expire?

A static QR code stores the text or URL used to create it. The image itself does not have an expiry timer, but a website destination can change or stop working.

Is my QR code content private?

This page uses the public QRServer/goQR service to render the image. The URL or text you enter is sent to that third-party service, so do not enter passwords, private tokens or confidential information.

Privacy notice

Important: QR images are rendered through the public QRServer/goQR service. The URL or text you enter is sent to that third-party service as part of the image request. Do not enter passwords, private tokens, payment details or confidential information.
