This free QR code maker turns a website URL or plain text into a scannable QR code. Generate a preview, choose PNG for everyday use or SVG for scalable artwork, and save the file to your device.

How to make a QR code

  1. Enter the complete website address or the text you want to share.
  2. Choose an output size and error-correction level.
  3. Select PNG or SVG as the download format.
  4. Press Generate QR Code to display the preview.
  5. Download the QR image and scan-test it with a phone before printing or sharing.

PNG or SVG: which should you choose?

PNG is a raster image that works well for documents, websites and everyday sharing. SVG is a vector image that can be resized without becoming pixelated, making it useful for many design and print workflows. Keep a clear white margin around the QR code so scanners can detect its edges.

What is QR error correction?

Error correction adds backup information so a QR code may still scan if part of it is dirty or damaged. Higher correction levels create denser patterns and can require more space. For a simple website link, Medium is a practical starting point. Always test the finished image at the size and distance where people will scan it.

QR code generator FAQs

Can I generate a QR code for any website URL?

Yes. Paste the full URL, including https://, then generate and download the QR code. Make sure the destination page is public and works before sharing it.

Can I download my QR code as PNG or SVG?

Yes. Choose PNG for a standard image file or SVG for a vector graphic, then use the Download QR Code link after generating the preview.

Does a static QR code expire?

A static QR code does not have an automatic expiry date. It stores the URL or text encoded when it was created, but the destination website can change or stop working.

Is the text I enter uploaded?

No external QR image service is used. The QR pattern is generated in your browser. The QR library is downloaded from a public CDN, but your entered text is processed locally by the page.

Why won't my QR code scan?

Try a larger image, keep the white margin, avoid making the pattern too small, and choose a lower error-correction level for long text. Test the saved image with more than one phone before printing.
