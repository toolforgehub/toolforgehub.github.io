# ToolForgeHub Adsterra setup

The package includes clearly labeled ad slots. Do not paste fake or generic ad code. Use the exact code generated in your Adsterra publisher dashboard.

Recommended rollout:
1. Start with one Social Bar code site-wide. Adsterra's current publisher guide says Social Bar is added by placing the script before the closing `</body>` tag.
2. Test one banner or native slot on tool pages.
3. Keep ads away from tool action buttons, upload controls and fake download links.
4. Review revenue and user experience before adding another slot.

Do not use bot traffic, incentivized clicks, fake clicks or self-clicking.
