Image tools for common file tasks

Use these utilities when an image is too large, has the wrong dimensions or needs a different file format. Choose a tool below, follow its controls and review the output before uploading or sharing the file.

Choose an image tool

  • Image Resizer — set exact pixel dimensions and optionally keep the original aspect ratio.
  • Image Compressor — export a JPEG copy and adjust its quality to balance detail and file size.
  • Image Dimensions Checker — inspect an image's width, height and file size.
  • Image to JPG — convert a browser-supported image to JPEG.
  • Image to PNG — export a browser-supported image as PNG.
  • Image to WebP — create a WebP copy where supported by the browser.
  • Image to Data URL — turn an image into a data URL for compatible development workflows.

Which image format should you use?

JPEG is commonly used for photographs and does not preserve transparency. PNG supports transparency and is useful for sharp graphics. WebP can offer smaller files for compatible websites, but check that the platform you use accepts it. Keep an original copy before converting or compressing important images.

Resize or compress?

Resizing changes the pixel width and height. Compression changes how image data is stored and can reduce file size. For a large photo, you may need both steps: resize to the display dimensions first, then compress a copy and compare its visual quality.

Privacy and performance

Most image conversion and resizing operations on these pages run in your browser. Large images can use significant device memory. Read each tool's note to understand its output format and any third-party service used.
