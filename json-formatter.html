Format and validate JSON online

Paste JSON into the editor, then choose Format JSON to make it easier to read or Minify to remove unnecessary whitespace. The tool parses the input first and shows an error message when the text is not valid JSON.

How to use the JSON formatter

  1. Copy your JSON data into the text box.
  2. Choose Format JSON to add indentation and line breaks.
  3. Choose Minify to produce a compact JSON string.
  4. Read the status message. If the JSON is invalid, use the reported parser error to locate the problem.
  5. Copy the corrected output into your code editor or application.

Example

Input: {"name":"Alex","active":true}

Formatted output:

{
  "name": "Alex",
  "active": true
}

Common JSON errors

  • Using single quotes instead of double quotes around strings.
  • Leaving a trailing comma after the final item in an object or array.
  • Forgetting a comma between properties.
  • Using an unquoted property name.
  • Leaving a bracket or brace unclosed.

Privacy

Formatting and validation use the browser’s built-in JSON parser. The page does not intentionally send the JSON text you enter to our website. Avoid using a shared computer for confidential data.
