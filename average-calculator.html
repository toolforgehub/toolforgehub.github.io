About Average Calculator

Use the Average Calculator to find the arithmetic mean, total, smallest value and largest value in a list of numbers. It accepts values separated by commas, spaces or line breaks.

How to use Average Calculator

Paste your numbers into the input box, separate them with commas or whitespace, and select Calculate. The result shows the number of valid values, their sum, average, minimum and maximum.

Frequently asked questions

What input format is supported?

Enter numbers separated by commas, spaces or line breaks. Non-numeric entries are ignored by the current calculator.
