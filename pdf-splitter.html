Split one PDF into multiple files

PDF Splitter divides one PDF into smaller documents using page break points. Enter the page numbers after which a new part should begin. The output PDFs are packaged together in a ZIP download.

How to split a PDF

  1. Select a PDF file.
  2. Enter page numbers after which to split, separated by commas.
  3. For example, enter 3, 6 to create pages 1–3, 4–6 and 7 onward.
  4. Leave the field empty to create one PDF file per page.
  5. Select Split PDF and download the ZIP archive.

What happens to the original file?

The original PDF is not changed. The tool reads its pages and creates separate output documents in your browser. Keep a backup of important documents and open the output files to verify the split points.

Privacy and limitations

PDF processing runs locally in the browser and the selected PDF is not intentionally uploaded to ToolForgeHub. Very large documents can exceed available browser memory. Some encrypted or unusual PDFs may not open.
