PDF processing uses the open-source pdf-lib browser library loaded from jsDelivr. Your selected PDF is processed in the browser; our site does not upload it to our own server.

Merge PDF files online

Choose two or more PDF files to combine them into one document. Select the files in the order you want them to appear, then choose Merge PDFs. The merged file is downloaded as merged.pdf.

How to combine PDF files

  1. Select at least two PDF files from your device.
  2. Check the selection order before merging; pages are added in the order the files are selected.
  3. Choose Merge PDFs.
  4. Wait for the browser to process the documents and download the merged PDF.
  5. Open the downloaded file and check page order and readability.

Common reasons to merge PDFs

Combine scanned pages, application documents, invoices, receipts, class notes, reports or a contract with its supporting pages. Merging keeps the pages together in a single PDF; it does not rewrite the text or edit individual page contents.

Privacy and file limits

The merge operation reads the selected PDFs in your browser and creates the output there; the page code does not upload the selected PDF files to our website. Your browser’s available memory and the size or complexity of the files can affect performance. Very large files may fail on phones or devices with limited memory.

Before merging

  • Make sure every file opens correctly before selecting it.
  • Use clear filenames so you can select files in the right order.
  • Check the final PDF after downloading, especially when documents contain forms or scanned pages.
